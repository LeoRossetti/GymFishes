  `capture2.mjs`, `gif.py`, `ladder.py`, `allfish.py`, `perfil.mjs`. They need a dev server:
  `npx vite --port 4175 --strictPort` (stop only your own PID afterwards). `capture2.mjs <tag> [--gif]`
  takes environment variables: `SCEN` (stand-in scenario: `aquario`, `aquario-25`, `nivel-<ml>`),
  `LEO_ML`, `HAB=fresh|salt`, `LEO_FISH=<fish id>` and `VW=<viewport width>`. Example, every saltwater fish
  in a full reef: `HAB=salt LEO_FISH=whale SCEN=nivel-3000 LEO_ML=3000 node .tmp/m10/capture2.mjs f-whale`,
  then `python .tmp/m10/allfish.py`. The stand-in is `.tmp/review-final/pairs/mock.mjs`.
- **For a fish contact sheet:** `npm run fish:sheet` launches WebKit, which crashed for every agent in
  October; switch that script to Chromium, or render through `capture2.mjs` with `LEO_FISH`.
- **Lessons that cost time:** Playwright video records at 1×, so for exact GIFs seek every animation with
  `document.getAnimations()` and fit whole cycles into the loop (see `capture2.mjs`'s `seek`). Run Pillow
  scripts with plain `python` (not `-I`). Long Bash heredocs with quotes break the shell wrapper: write
  the script to a file first. Repo files are CRLF: edit them with a short Python script that keeps the
  line endings, or with the Edit tool after a Read.
